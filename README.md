# SHATTERBOUND

An interactive fighting-game concept reveal for Danny, available in English and Mexican Spanish.

Explore the story, choose Jace Colton or Kai Suriya, charge their ability meters, view the original character posters, and choose how to help build the game. Ability previews are illustrative; this is not playable combat.

## Website

Intended GitHub Pages URL: https://jkgraphix11.github.io/shatterbound-concept/

Publish from the `main` branch and `/(root)` in repository Settings → Pages. This repository must be public for the requested public launch.

## Artwork

The six original approved WebP files are stored beside `index.html`. Their filenames and image bytes are preserved. The page shows complete posters without cropping and offers an enlarged gallery.

## Validation

- All six WebP images decoded and displayed successfully in browser QA.
- Story navigation, browser back navigation, character selection, ability charging/finishers, poster gallery, and Join choices exercised.
- English and Mexican Spanish (`es-MX`) labels, abilities, poster captions, role feedback, and roster status verified.
- Responsive layouts checked at widths from 320 to 844 pixels without horizontal page overflow.
- Safe-area padding, touch target minimums, reduced-motion handling, and Safari-prefixed text clipping included.
- Browser QA used Chrome with phone-width frames. Actual iPhone Safari and the public Pages deployment still require verification after publishing.

No build step or external JavaScript dependencies are required. Google Fonts is optional; system font fallbacks are included.
